# Lumina Launcher

Minecraft Java Edition launcher แบบเดสก์ท็อป พร้อม Local Profile (ไม่ต้องล็อกอิน) และ UI ภาษาไทย

## เริ่มใช้งาน

```powershell
npm install
npm start
```

Launcher จะใช้โฟลเดอร์ `%APPDATA%\.minecraft` เป็นค่าเริ่มต้น และสามารถดาวน์โหลดไฟล์เวอร์ชันที่เลือกจากเซิร์ฟเวอร์ทางการของ Mojang ได้ การเล่นแบบ Local Profile เหมาะกับ Singleplayer/LAN และเซิร์ฟเวอร์ที่อนุญาต offline mode เท่านั้น บัญชีออนไลน์และเซิร์ฟเวอร์ที่เปิดการยืนยันตัวตนยังต้องใช้บัญชี Microsoft ที่มีสิทธิ์ตามปกติ

## ความต้องการ

- Windows 10/11
- Java ที่ตรงกับเวอร์ชันเกม (Minecraft รุ่นใหม่แนะนำ Java 21)
- Node.js 20 ขึ้นไป
